# Dynomax 1.0.4 and Demo Project

This package:

- Adds clipboard handoff for validated result ZIP files.
- Includes project-generated `project-export` files in the result ZIP and SQL artifacts.
- Removes `pause` from the workflow template.
- Installs `DYNOMAX_AGENT_GUIDE.md` in the Dynomax root.
- Installs the project-neutral `Dynomax-Demo` project.
- Runs a composed five-action workflow against the configured ATX public home page.
- Does not load the ATX Solutions project or use ATX credentials.
